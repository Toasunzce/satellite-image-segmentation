
# About
---
Цель этого проекта - анализ сегментации изображений с использованием классических алгоритмов кластеризации. В рамках проекта было использовано несколько допущений:
- не выходить за рамки классического МО, несмотря на то, что с задачей сегментации лучше всего справляются модели глубокого обучения, например U-net.
- использовать не весь датасет изображений, а лишь наиболее простые в рамках поставленной задачи.
